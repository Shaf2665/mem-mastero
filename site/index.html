mem-mastero

Your coding agent's sessions and memory follow each repo across every machine.

GitHub Documentation

Claude Code, Codex, Copilot CLI and Pi keep session history locally. mem-mastero brings those original sessions and memory files to your other machines.

It syncs through storage you own, either a private GitHub repo or Google Drive. Sync runs through agent lifecycle hooks. Optional Git hooks also sync when you git push, git pull or git clone.

Get started

Requires Node.js 18.17+ and git. For the GitHub option, GitHub CLI signed in with gh auth login.

npx github:Shaf2665/mem-mastero setup

Run that one command on every machine. Projects are matched by their git remote, not their folder path, so D:\Work\app on your PC and ~/code/app on your Mac share the same sessions.

Setup walks through three steps:

  1. Connects your memory repo. It finds the repo on the account you picked, or creates it as private.
  2. Installs the plugin into every coding agent it finds: Claude Code, Codex, Copilot CLI and Pi.
  3. Offers optional sync for git push / git pull / git clone, for every repo on the machine.

Measure storage. Archive Claude sessions safely.

See how much space sessions, companion files and existing memory clones use. Preview old sessions before choosing what to archive:

npx --yes github:Shaf2665/mem-mastero storage
npx --yes github:Shaf2665/mem-mastero archive --dry-run

With Claude closed, explicitly archive a session to your private GitHub memory repository. mem-mastero uploads it, downloads the cloud copy and verifies every file before removing unchanged local session files. Restore the archive when you need to resume that conversation.

Archiving currently supports Claude Code with private GitHub storage. Durable auto-memory stays local; existing memory clones and Git history are retained. Archive and restore instructions

Personal and work accounts

Run setup once per account. A work memory repo takes only the projects you list for it; everything else goes to your personal one, so company memory stays in the company account.

Security and privacy

  • Transcripts can contain anything you pasted or a tool printed. Store them only in a private repo, or a Drive you control.
  • mem-mastero stores no tokens or passwords. Sign-in is handled by GitHub CLI and Git Credential Manager.
  • No npm dependencies or server to manage. Uses Node.js and Git, plus authenticated GitHub CLI for GitHub storage.
